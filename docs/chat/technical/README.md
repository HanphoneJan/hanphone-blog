## 💡 核心亮点速览

### 1. 🧠 四层记忆架构（行业领先）

- **L1 工作记忆**：当前对话上下文（最近3轮）
- **L2 短期记忆**：会话历史，PostgreSQL存储
- **L3 长期记忆**：跨会话持久化，Qdrant向量检索
- **L4 核心记忆**：用户画像，结构化关键信息

> **面试亮点**：区别于普通ChatBot的"金鱼记忆"，实现真正的"越聊越懂你"

### 2. 📉 记忆遗忘算法（算法创新）

基于**艾宾浩斯遗忘曲线**的数学模型：

```
S(t) = S₀ × e^(-λt) × (1 + α × access_count)
```

- 重要性高的记忆衰减慢
- 频繁访问会刷新记忆强度
- 自动识别并清理低价值记忆

### 3. 🎯 多模式推理系统

| 模式     | 适用场景   | 特点                 |
| -------- | ---------- | -------------------- |
| quick    | 日常问候   | 直接响应，无思考过程 |
| standard | 一般问题   | 单轮思考后回答       |
| deep     | 复杂分析   | 多轮思考、自我修正   |
| plan     | 多步骤任务 | 工具链编排执行       |

### 4. 🔧 MCP工具生态

- **10+工具**：搜索、天气、计算、翻译、代码执行等
- **工具链编排**：支持多工具依赖执行
- **代码沙箱**：安全的Python/JS/Bash代码执行环境

### 5. 🛡️ 内容安全体系

- 输入过滤：风险检测、PII识别
- 输出脱敏：敏感信息自动替换
- 分级处理：高/中/低风险差异化响应

## 🎤 面试话术速记

### ⏱️ 1分钟版本（电梯演讲）

```
HanPhone Chat 是一个具有长期记忆能力和公共聊天室的AI聊天系统。

核心创新点是四层记忆架构：工作记忆、短期记忆、长期记忆、核心记忆。
区别于普通ChatBot的"金鱼记忆"，它能记住用户的偏好、习惯，实现"越聊越懂你"。

技术栈是 React + Node.js + Python FastAPI，使用 Qdrant 向量数据库存储长期记忆，
实现了多模式推理、工具调用、公共聊天室、内容安全过滤等企业级功能。
```

### ⏱️ 3分钟版本（标准介绍）

```
HanPhone Chat 是一个生产级的AI聊天系统，我负责其中 Agent 服务的设计与实现。

系统采用三层架构：前端 React、后端 Node.js、Agent 服务 Python。

最大的技术亮点是四层记忆系统：
1. L1 工作记忆：当前对话的瞬时上下文
2. L2 短期记忆：当前会话的历史记录，存在 PostgreSQL
3. L3 长期记忆：跨会话的持久化记忆，使用 Qdrant 向量数据库做语义检索
4. L4 核心记忆：用户画像，存储关键偏好和事实

我还实现了基于艾宾浩斯遗忘曲线的记忆遗忘算法，让记忆随时间自然衰减，
重要信息保留更久，避免记忆膨胀。

另外有多模式推理（4种模式）、工具链编排、内容安全过滤等功能。
代码量约1.4万行，10+个MCP工具，支持流式SSE响应。
```
