# 云林有风 Android 客户端 · 整体实施计划

> ⚠️ **本文件为历史路线图存档**：早期实施记录（含 5Tab/归档独立页等旧设计）均已演进，
> 最新架构与规矩以 **[HANDOVER.md](HANDOVER.md)** 为准，勿按本文旧描述实现。

> 目标：用**原生 Kotlin + Jetpack Compose（Material 3）**，依托博客现有 REST API，
> 做成一个符合**国内主流 App 交互习惯**的自用客户端。前端只消费 API，后端零改动。

## 状态说明

- 每轮迭代遵循：**计划 → 实现 → 构建 → 真机验证 → 复盘**
- 交互基线：底部导航 / 下拉刷新 / 分类筛选 / 快速搜索 / 底部操作栏 / 轻提示(Toast/Snackbar) / 系统返回
- 每个功能落地标准：真机上 UI 树可见 + 数据来自生产 API + 无 FATAL 崩溃

## 已完成（v1.1，已装机验证）

| 模块 | 说明 |
|---|---|
| 工程 | Gradle 8.11 + AGP 8.7 + Kotlin 2.0 + Compose M3，单模块分层（data/core/ui/util） |
| 导航 | 底部导航 5 Tab（首页/随笔/归档/留言/我的）+ 详情/搜索子路由 |
| 首页 | 分类标签筛选 + 下拉刷新 + 无限滚动 + 搜索入口 |
| 详情 | Markdown 渲染 + 评论列表 + 匿名评论 + 点赞/评论/分享操作栏 |
| 随笔 | 图文信息流 + 详情 + 评论展示 |
